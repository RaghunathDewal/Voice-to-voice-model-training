# Third-party components

This project builds on the following pretrained models, datasets and tools. Each keeps its own
licence. Check the original licence page before any commercial use; this list is a summary,
not legal advice.

## Pretrained models (used at runtime)

| Component | Use | Licence |
|---|---|---|
| [NVIDIA Parakeet-CTC-0.6B](https://huggingface.co/nvidia/parakeet-ctc-0.6b) | speech encoder (frozen) | CC BY 4.0 |
| [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) | thinker (fine-tuned with LoRA) | Apache-2.0 |
| [Kyutai Mimi](https://huggingface.co/kyutai/mimi) | audio codec (frozen) | CC BY 4.0 |

## Used only to create training data

| Component | Use | Licence |
|---|---|---|
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | synthetic speech for training data (voice `af_heart`) and demo guest voice | Apache-2.0 |

## Datasets

| Dataset | Use | Licence |
|---|---|---|
| Common Voice | speech understanding | CC0 |
| People's Speech | speech understanding | CC BY / CC BY-SA |
| VoxPopuli | accented speech | CC0 |
| EdAcc | accented conversational speech | CC BY-SA 4.0 (verify) |
| Svarah (AI4Bharat) | Indian-English speech, test set | CC BY 4.0 |
| LJSpeech | talker experiments | public domain |
| xLAM function-calling 60k (Salesforce) | tool-call training | CC BY 4.0 |
| Hermes function-calling | tool-call training | Apache-2.0 |
| Hotel dialogues (`s2s/data/hotel.py`) | generated by this project | (this repository) |

The hotel test sets are synthetic: template sentences spoken by Kokoro voices.

SLURP and SpokenWOZ have presets in `s2s/prep/hf_asr.py` but are **not used** in the current
checkpoints: their original releases are non-commercial.
