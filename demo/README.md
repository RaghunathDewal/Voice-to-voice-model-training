# Demo video

60 s, 1080p walkthrough of the voice concierge UI (`s2s/cli/static/live.html`) replaying a
conversation generated by our own model.

1. `scripts/guest.py` - guest questions spoken with Kokoro (am_michael); these are only the *input* voice.
2. `scripts/run_agent.py` - runs the real VoiceAgent (speech LLM + talker) on those wavs -> bot replies,
   tool calls and `conversation.json`.
3. `scripts/record.py` - Playwright opens the UI in demo-replay mode (`/?demo=demo`), clicks through it,
   records the session and takes a screenshot at each step.
4. `scripts/storyboard.py` - writes `video/storyboard.json` (captions, narration, highlights, audio cues).
5. `video/` - Remotion project: `npm i && npm run render` -> `out/voice-concierge-demo.mp4`
   (needs `public/recording.webm` from step 3).

Latency numbers shown are from the live WebSocket test on a Kaggle T4.
